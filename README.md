# Peter Fung Portfolio

My personal portfolio site, built to share my projects, work experience, and a little bit about how I like to build.

Live site: [https://www.peterjosephfung.com](https://www.peterjosephfung.com)

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
